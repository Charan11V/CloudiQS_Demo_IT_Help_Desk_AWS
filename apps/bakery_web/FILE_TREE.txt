🚀 HOW TO RUN:

1. Quick Start (Automated):
   Windows:  .\start.bat
   Linux:    ./start.sh

2. Manual:
   npm install
   npm run dev

3. Docker:
   docker build -t bakery-web .
   docker run -p 3000:3000 bakery-web

Opens at: http://localhost:3000
Expects API at: http://localhost:8002
